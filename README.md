# Jevent Design — Website

Official website for **Jevent Design** — Sydney floral artistry & wedding day-of coordination.

## Tech Stack
- React 19 + TypeScript
- Vite 7
- Tailwind CSS 3.4 + shadcn/ui
- GSAP (ScrollTrigger), Framer Motion, Lenis

## Getting Started
```bash
npm install
npm run dev      # local development
npm run build    # production build → dist/
```

## Structure
- `src/pages/` — 8 pages (Home, Floral Design, Coordination, Corporate, Silk Rentals, Real Weddings, Investment, Enquiry)
- `src/components/` — shared Navbar, Footer, Layout, UI primitives
- `src/data/` — content data (real weddings gallery, collections)
- `public/` — photography, brand logos, badges, icons
